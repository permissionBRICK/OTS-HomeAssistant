Version 2.3.0 backs up the heat pump's settings and restores them (#35).

- **Settings backups:** curves, heating limits, building inertia, setpoints, operating programs, circuit names and time programs. One is taken automatically when Home Assistant starts, if something changed, and **Back up settings** on the device page takes one on demand. A backup only reads the controller, and Home Assistant's own backups include them.
- **Restore:** **Configure → Restore heat pump settings from a backup** lists what differs and writes only the settings you tick. **Download diagnostics** saves the backups to a file you can restore from.
- **No more deprecation warnings** after a restart on Home Assistant 2026.11.
