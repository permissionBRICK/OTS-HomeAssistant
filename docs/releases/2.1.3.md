The network search that finds a heat pump after an IP address change now only sends the factory default username, password and PIN. If you entered custom credentials in the advanced settings, they only go to the heat pump's saved address and to the address Home Assistant's DHCP data shows for its MAC address. They're no longer sent to every device on the subnet.

If a heat pump with custom credentials can't be found at either address, Home Assistant shows a repair issue. The new **Reconfigure** option in the integration entry's menu lets you enter a new address. The heat pump's serial number must match, and existing entities, devices and history are kept.

Update **Ochsner Local OTS** to **v2.1.3** in HACS, then fully restart Home Assistant. With the default credentials, nothing changes.

New tests cover the credential check, recovery through the DHCP address without a subnet search, the repair issue and the reconfigure flow. No live heat-pump test was performed for this patch.
